# Einf-hrung-in-die-Digitale-Provenienzforschung
Dieses Dokument ist eine Open Educational Ressource (OER) zum Thema "Einführung in die Digitale Provenienzforschung". Die OER richtet sich an Einsteiger:innen und Personen ohne Vorkenntnisse, die sich erstmals mit (digitaler) Provenienzforschung beschäftigen.
